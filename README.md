# Cherry Refrigeration — cherryrefrigeration.com.au

High-converting, SEO-dominant Next.js 14 site for Cherry Refrigeration, Brisbane's cold room installation specialists. Built to outrank Auscool, Instacold, Kolda, Taylor Refrigeration, Allfrige, RHQ, Elite and Brisbane Insulated Builders for "cold room installation Brisbane" and adjacent keywords.

## Stack

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS (custom palette: navy `#0B1F3A`, ice `#F4F8FB`, cherry `#C8102E`, steel `#3A4A5C`, frost `#A9D6E5`)
- React Hook Form + Zod for validation
- Resend for transactional email
- Cloudflare Turnstile for spam protection
- next/font (Inter + Manrope)
- next-sitemap for XML sitemap fallback
- Deployed to Vercel

## Quickstart

```bash
npm install
cp .env.example .env.local      # fill in keys
npm run dev                      # http://localhost:3000
```

### Environment variables

| Var | Purpose |
| --- | --- |
| `SITE_URL` | Canonical site URL (used in sitemap and metadata) |
| `RESEND_API_KEY` | Resend API key for outbound quote emails |
| `QUOTE_TO_EMAIL` | Inbox to receive quote requests (default `service@cherryrefrigeration.com.au`) |
| `QUOTE_FROM_EMAIL` | Verified Resend sender |
| `QUOTE_WEBHOOK_URL` | Optional webhook (Make/Zapier) for backup CRM ingestion |
| `TURNSTILE_SECRET_KEY` | Cloudflare Turnstile secret |
| `NEXT_PUBLIC_TURNSTILE_SITE_KEY` | Cloudflare Turnstile site key (client) |
| `NEXT_PUBLIC_GA_ID` | Google Analytics 4 ID (default `G-QCM5GYXMSH`) |

## Forms

- `src/components/QuoteForm.tsx` — single-step or multi-step (3 steps) form with React Hook Form + Zod, honeypot, Turnstile slot, success state.
- `src/app/api/quote/route.ts` — server route. Verifies Turnstile, sends via Resend, dual-fires webhook for CRM, validates payload with Zod.

## Performance budget

- LCP < 2.0s
- CLS < 0.05
- INP < 200ms
- Lighthouse 95+ all pillars

Achieved via:
- Static generation for every service / industry / location page (`generateStaticParams`)
- next/font with `display: swap` and variable fonts
- next/image (drop in real images later)
- No third-party chat widgets — quote form is in-house
- Tailwind's content-aware tree-shaking

## Accessibility

- WCAG 2.1 AA target
- Skip-to-content link on every page (`src/app/layout.tsx`)
- Semantic HTML5 (`<main>`, `<nav>`, `<article>`, `<section>`)
- Visible focus rings (`focus-visible:ring-cherry`)
- Form fields use `<label>` with explicit `for`/`htmlFor`

## Deploy
